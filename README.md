# carein — 돌봄 재무 내비게이터

2026 금융 AI Challenge 출품작.

부모 돌봄이 시작된 자녀에게 **흩어진 제도를 찾아 조합하고, 앞으로 10년의 비용과
"퇴사할까 말까" 같은 실제 결정을 근거와 함께 계산해주는** 웹서비스.

## 왜 이 자리인가

돌봄 시장의 모든 주체가 **돌봄 받는 사람**을 본다. **돌보는 사람**은 아무도 안 본다.
자산이 줄어드는 고객이라 아무의 수익원이 아니기 때문이다.
관심의 공백이 아니라 인센티브의 공백이고, 그래서 비어 있다.

## 아키텍처 — LLM은 숫자를 만들지 않는다

```
판정 = 지식베이스(제도 원문) + 룰엔진(계산)     ← 모델과 무관
LLM  = 문서 판독 + 설명 문장 생성                ← 교체 가능
```

금액도 자격 판정도 전부 결정론적 규칙이 한다. LLM은 영수증을 읽고 결과를 설명할 뿐이다.
그래서 **온프레미스 소형 모델로 갈아끼워도 판정 결과가 바뀌지 않는다.**
금융권 망분리 환경에 그대로 들어갈 수 있고, 파인튜닝한 모델은 이 주장을 할 수 없다.
프로바이더는 셋이다 — 온프레미스 sLLM, Gemini, Claude. 기본값은 온프레미스다.

내부망 모델(Ollama + LG exaone3.5 7.8B)로 실제 검증한 결과, 자산 유지 기간·월 실부담·
제도 판정 14건·퇴사 손익이 Claude API 모드와 **완전히 일치**했다. 차이는 문서 판독 품질과
응답 속도뿐이다.

| 태그 | 역할 |
|---|---|
| `VLM` | 등급판정 통지서·진단서·영수증 판독 |
| `EMB` | 복지제도 색인·매칭 |
| `RAG` | 제도 요건 대조 판정 |
| `GEN` | 설명·초안 생성 |
| `RULE` | **AI 아님.** 금액 계산 전담 |
| `GUARD` | 환각 차단·인젝션 방어·PII 마스킹 |

## 실행

```bash
npm install
cp .env.example .env.local
npm run dev
```

기본값은 온프레미스다. Ollama 를 띄워 두면 문서 판독과 설명 생성까지 동작한다.

```bash
ollama pull exaone3.5:7.8b
```

모델이 없어도 제도 판정·비용 계산·10년 시뮬레이션·퇴사 손익은 전부 동작한다.

외부 API 를 쓰려면 `AI_PROVIDER=claude` 와 `ANTHROPIC_API_KEY` 를 설정한다.

## 데이터 출처

모든 수치는 공개 자료에서 교차 검증했다. 값마다 화면에 출처가 표시된다.

| 데이터 | 출처 |
|---|---|
| 재가급여 월 한도액 / 시설급여 수가 | 보건복지부 2026년 장기요양 급여비용 고시 |
| 본인부담률·경감 기준 | 노인장기요양보험법 시행령 |
| 가족요양비 (월 240,450원) | 2026년 특별현금급여 고시 |
| 요양병원 간병비 급여화 | 보건복지부 추진방안 (2026.7.28) |
| 제도 요건·신청처 | 각 제도 근거 법령 (코드에 개별 명시) |

향후 공공데이터포털 복지서비스 API(한국사회보장정보원 중앙부처·지자체, 행안부 공공서비스)를
색인해 시드 지식베이스와 병합한다.

## 정직성 규칙

1. **모르면 해당한다고 말하지 않는다.** 판정은 해당 / 미해당 / 확인필요 3값이다.
2. **확인 안 된 제도는 금액 합계에 넣지 않는다.**
3. **추정이 들어간 가정은 전부 화면에 공개한다.** 확신도까지 표시한다.
4. **지급을 확정하지 않는다.** 최종 판단은 공단·보건소·고용노동부가 한다.
5. **건강·소득 정보를 저장하지 않는다.**

## 구조

```
src/
  lib/engine/    rates.ts    2026 급여 기준값 (출처 명시)
                 cost.ts     비용 산출 (RULE)
                 match.ts    제도 자격 판정 (RULE)
                 simulate.ts 다년 현금흐름 (RULE)
                 decision.ts 퇴사 vs 유지 (RULE)
                 analyze.ts  오케스트레이터
  lib/kb/        programs.ts 제도 지식베이스
  lib/ai/        provider.ts 모델 어댑터 + 가드레일
  app/api/       analyze     LLM 미개입. 순수 계산
                 explain     LLM 개입하는 유일한 경로
```
