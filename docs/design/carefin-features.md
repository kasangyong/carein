# 기능 명세 (설계안) — 돌봄 가족 재무 내비게이터

작성일: 2026-09-01 · 브리프: [product-brief.md](../product-brief.md) · 데이터: [data-inventory.md](../data-inventory.md)

## AI 역할 6종

기획서 5번 "생성형 AI 모델 적용 방안"에 그대로 대응. 기능마다 태그를 붙여 AI가 **무엇을 하고 무엇을 하지 않는지**를 명시한다.

| 태그 | 역할 |
|---|---|
| `VLM` | 비정형 문서 이해 — 등급판정 통지서·진단서·급여명세서 |
| `EMB` | 의미 검색·정규화 — 복지제도 수천 건 색인·매칭 |
| `RAG` | 근거 기반 판정 — 제도 요건 대조 |
| `GEN` | 자연어 생성 — 설명·초안·요약 |
| `RULE` | **AI 아님. 결정론적 계산 전담** |
| `GUARD` | AI 통제 — 환각 차단·인젝션 방어·PII 마스킹 |

> **철칙: 금액에 관여하는 계산은 전부 `RULE`. LLM은 단 한 번도 숫자를 만들지 않는다.**

## 데모 핵심 루프 (심사위원 3~5분, 발표자 없이)

```
[상황 입력]   프리셋 선택 or 등급판정 통지서 업로드           30초
     ↓
[제도 발굴]   몰랐던 제도 7개 · 연 1,240만원                  60초
              각 제도에 사업명·근거·신청처
     ↓
[비용 산출]   실부담 월 187만원 (제도 적용 전 342만원)        30초
              계산 과정 전개
     ↓
[다년 계산]   이대로면 부모님 자산은 4년 3개월 뒤 소진        40초
     ↓
[결정 지원]   퇴사 vs 유지
              직관: 퇴사 (월 50만원 이득)
              실제: 5년 누적 -8,700만원 → 유지가 유리        60초
              ← 여기가 임팩트. 답이 뒤집힘
     ↓
[실행]        신청 순서 + 서류 체크리스트 + 기한              30초
```

**기억에 남길 두 숫자: 몰랐던 제도 7개 / 연 1,240만원, 그리고 퇴사하면 5년 뒤 -8,700만원.**
전자는 발견, 후자는 반전. 표가 아니라 결론이 남는다.

메인 루프는 M1~M6만 사용. M11 이상은 별도 탭.
