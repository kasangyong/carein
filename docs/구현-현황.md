# 구현 현황

최종 확인: 2026-09-02 · 로컬 프로덕션 빌드에서 전 항목 실동작 재검증

## 검증 방법

```bash
npx tsc --noEmit          # 타입 — 통과
npx eslint src            # 린트 — 경고 0
npm run build             # 빌드 — 12개 라우트
npm run start             # 프로덕션 서버
```

Next.js 앱은 저장소 루트에 있다. 하위 폴더가 아니므로 Vercel Root Directory 는 비워 둔다.

브라우저 자동화로 실제 조작까지 확인했다. 아래 "확인됨"은 코드가 존재한다는 뜻이 아니라
**화면에서 눌러서 동작을 봤다**는 뜻이다.

## 온프레미스 실검증

망분리 주장을 말로만 두지 않고 실제로 돌려 확인했다.

```bash
AI_PROVIDER=onprem ONPREM_BASE_URL=http://localhost:11434 ONPREM_MODEL=exaone3.5:7.8b npm run start
```

| 항목 | 외부 API (Claude / Gemini) | 온프레미스 exaone3.5 (7.8B) |
|---|---|---|
| 자산 유지 기간 | 2년 → 9년 9개월 | **동일** |
| 월 실부담 | 1,140,000원 | **동일** |
| 제도 판정 | 해당 14건 · 놓치기 쉬운 7건 | **완전 일치** |
| 퇴사 손익 | 78,450,894원 (반전 성립) | **완전 일치** |
| 설명 문장 생성 | 가능 (Gemini 13.9초 / Claude 수초) | 가능 (한국어, 63초) |
| 가드레일 | 근거 없는 금액 0건 | **동일하게 통과** |
| 데이터 외부 전송 | 있음 (PII 마스킹 후) | **없음** |

차이는 문서 판독 품질과 응답 속도뿐이다. 돈과 자격에 관한 값은 한 자리도 안 바뀐다.

당연한 결과다. `/api/analyze` 는 LLM을 아예 호출하지 않는다. 판정과 금액은 지식베이스와
룰엔진이 만들고, LLM은 그 결과를 문장으로 옮길 뿐이다. 위 표는 그 설계가 실제로
그렇게 동작하는지 확인한 기록이다.

## 개발 중 찾아 고친 것

기능을 추가한 것보다 **틀린 것을 고친 것**이 결과를 바꿨다.

| 발견 | 문제 | 조치 |
|---|---|---|
| 게이지가 둘 다 10년으로 채워짐 | `simulate`가 간병 유형을 안 받아 개인간병(390만)을 공동간병(100만)으로 계산 | 비용 세부를 시뮬레이션까지 전달 |
| 퇴사 반전이 안 나옴 | 돌봄 기간이 42개월인데 돌봄비를 10년 내내 부과. 퇴사 쪽이 없는 절감액을 6년치 더 받음 | 돌봄비를 `careDurationMonths` 안으로 제한 |
| 등급 없는데 3등급 비용이 나옴 | 등급 미보유 시 기본값 "3"으로 대체 | 등급 미보유를 별도 경로로 분리. 전액 자부담 |
| 인지지원등급 시설 59만원 | 이용 자체가 안 되는데 비급여만 계산됨 | 이용 불가 조합을 금액 대신 "이용 불가"로 반환 |
| 가족 직접돌봄 0원 | 직접 돌봐도 의료비·소모품은 든다 | 방문요양 부분 이용 + 소모품 반영 |
| 레드팀 7/8 | 한국어 조사 처리 오류 — "지시사항**을** 무시"가 `를?` 패턴을 빠져나감 | 조사를 느슨하게 잡도록 패턴 13종으로 재작성 → 8/8 |
| 한글 자간 붕괴 | mono 폰트에 한글 글리프가 없어 generic monospace로 fallback | `.num` 폰트 스택에 한글 sans 삽입, 라벨은 sans로 |
| `17,163만원` | 억 단위를 만원으로 세어 읽히지 않음 | 1억 넘으면 억 단위로 끊는 포매터 |
| 폰트 preload 경고 190개 | 한글 서브셋 전량 preload | KR 폰트 `preload: false` |
| 쉬운 말 토글이 무동작 | CSS만 만들고 컴포넌트에서 안 씀 | `Term` 컴포넌트 구현 → 이후 헤더 정리로 제거 |
| 확정표현 치환이 비문 생성 | "지원받을 수 있습니다" → "지원요건을 충족하면 대상이 됩니다" | 동사 어간을 캡처해 보존하도록 규칙 재작성 |
| 화면마다 헤더가 어긋남 | 메인에만 컨트롤이 붙어 nav 위치가 다른 화면과 달랐음 | 공통 `SiteHeader` 로 통일, 컨트롤 제거 |
| 배포는 Ready인데 전 경로 404 | Next.js 앱이 `app/` 하위에 있어 저장소 루트에 `package.json` 이 없었음. 빌드 없이 정적 파일만 올라감 | 앱을 저장소 루트로 이동 |
| 빌드가 1초 만에 실패 | Root Directory 설정이 옮기기 전 경로(`app`)로 남아 있었음 | 값을 비움 |
| 모든 URL이 로그인 화면으로 튕김 | Vercel Deployment Protection 기본 활성. 심사위원이 열면 302 → `vercel.com/sso-api`. **대회 결격 사유** | 보호 해제 후 미로그인 상태로 재확인 |
| 배포 환경에서 `fetch failed` | 프로바이더 기본값이 온프레미스라 Vercel 서버가 자기 자신의 `localhost:11434` 를 호출 | 실패 메시지에 원인과 조치를 담고, 배포 시 `AI_PROVIDER` 를 명시 |
| Gemini 404 | `gemini-2.5-flash` 가 신규 사용자에게 더 이상 제공되지 않음 | 기본 모델을 `gemini-3.6-flash` 로 변경 |

## 배포

Git 저장소를 Vercel에 연결해 푸시할 때마다 자동 빌드한다. Next.js 앱이 저장소 루트에
있으므로 **Root Directory 는 비워 둔다.**

| 항목 | 값 |
|---|---|
| 저장소 | `github.com/kasangyong/carein` (`main`) |
| 빌드 | Vercel 기본 Next.js 프리셋. 별도 설정 없음 |
| Root Directory | **비움** — 하위 폴더 아님 |
| Deployment Protection | **해제 필수.** 켜져 있으면 심사위원이 로그인 화면으로 튕긴다 |

### 환경변수

없어도 **핵심 기능이 전부 동작한다.** 제도 판정·비용 계산·10년 시뮬레이션·퇴사 손익·
레드팀 콘솔은 LLM을 타지 않기 때문이다. 아래는 `AI 설명 받기` 와 문서 판독을 켜는 설정이다.

| 키 | 값 | 비고 |
|---|---|---|
| `AI_PROVIDER` | `gemini` | 미설정 시 `onprem` — 서버에 로컬 모델이 없어 실패한다 |
| `GEMINI_API_KEY` | 발급 키 | Google AI Studio |
| `GEMINI_MODEL` | `gemini-3.6-flash` | 생략 시 기본값 |

금융기관 내부망에 올릴 때는 `AI_PROVIDER=onprem` 과 `ONPREM_BASE_URL` 만 바꾼다.
판정과 금액은 그대로다.

**대회 요건**: 배포 URL이 2026-09-07 11:00 ~ 09-11 23:59 접근 가능해야 하며, 불가 시 결격.
제출 전 **로그아웃 상태에서** 5개 화면과 5개 API를 직접 열어 확인한다.
