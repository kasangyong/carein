최종 확인: 2026-09-02 · 로컬 프로덕션 빌드에서 전 항목 실동작 재검증

## 검증 방법

```bash
npx tsc --noEmit          # 타입 — 통과
npx eslint src            # 린트 — 경고 0
npm run build             # 빌드 — 12개 라우트
npm run start             # 프로덕션 서버
```

Next.js 앱은 저장소 루트에 있다. 하위 폴더가 아니므로 Vercel Root Directory 는 비워 둔다.

브라우저 자동화로 실제 조작까지 확인했다. 아래 "확인됨"은 코드가 존재한다는 뜻이 아니라
**화면에서 눌러서 동작을 봤다**는 뜻이다.

## 온프레미스 실검증

망분리 주장을 말로만 두지 않고 실제로 돌려 확인했다.

```bash
AI_PROVIDER=onprem ONPREM_BASE_URL=http://localhost:11434 ONPREM_MODEL=exaone3.5:7.8b npm run start
```

| 항목 | 외부 API (Claude / Gemini) | 온프레미스 exaone3.5 (7.8B) |
|---|---|---|
| 자산 유지 기간 | 2년 → 9년 9개월 | **동일** |
| 월 실부담 | 1,140,000원 | **동일** |
| 제도 판정 | 해당 9건 · 확인 필요 1건 · 놓치기 쉬운 5건 | **완전 일치** |
| 퇴사 손익 | 78,450,894원 (반전 성립) | **완전 일치** |
| 설명 문장 생성 | 가능 (Gemini 13.9초 / Claude 수초) | 가능 (한국어, 63초) |
| 가드레일 | 근거 없는 금액 0건 | **동일하게 통과** |
| 데이터 외부 전송 | 있음 (PII 마스킹 후) | **없음** |

차이는 문서 판독 품질과 응답 속도뿐이다. 돈과 자격에 관한 값은 한 자리도 안 바뀐다.

당연한 결과다. `/api/analyze` 는 LLM을 아예 호출하지 않는다. 판정과 금액은 지식베이스와
룰엔진이 만들고, LLM은 그 결과를 문장으로 옮길 뿐이다. 위 표는 그 설계가 실제로
그렇게 동작하는지 확인한 기록이다.

## 보안 점검

2026-09-02 전 코드·전 엔드포인트 점검. 아래는 실제로 확인한 것만 적었다.

### 이상 없음

| 항목 | 확인 내용 |
|---|---|
| 비밀값 | `.env*` 는 `.gitignore` 대상. 추적되는 건 값이 빈 `.env.example` 하나. 전체 히스토리에 키 문자열 없음 |
| XSS | `dangerouslySetInnerHTML`·`innerHTML`·`eval`·`document.write` 사용처 0. React 기본 이스케이프에 의존 |
| SSRF | 외부 호출은 프로바이더 한 곳. 엔드포인트 URL은 환경변수에서만 오고 요청값이 바꾸지 못한다 |
| 저장소 | `localStorage`·쿠키·DB·파일 쓰기 없음. "저장하지 않는다"는 주장과 코드가 일치 |
| 로그 | `console.*` 호출 0. 서버 로그로 개인정보가 샐 경로가 없다 |
| 의존성 | `npm audit` 취약점 0건. 런타임 의존성 5개 |
| 파일 업로드 | 8MB 상한, 4종 MIME 화이트리스트 |

### 찾아서 고친 것

| 발견 | 문제 | 조치 |
|---|---|---|
| `POST /api/analyze {"setting":"MARS"}` → **200** | 허용값 밖 입력에 그럴듯한 계산 결과를 돌려줬다. "모르면 해당한다고 말하지 않는다"는 1번 원칙과 정면으로 어긋난다 | 계산 전 형태 검증. 어느 필드가 왜 틀렸는지 400으로 응답 |
| 잘못된 본문에 **500 + 내부 오류 문구** | `Cannot read properties of undefined (reading 'ltcGrade')` 처럼 내부 구조가 그대로 나갔다 | 400/413/415로 분류하고 안내 문구로 교체 |
| `{"provider":"gpt9"}` → **500** | `getProvider` switch 에 `default` 가 없어 `undefined` 반환 | `default` 추가 + 라우트에서 사전 검증 |
| 마스킹이 날짜를 삼킴 | 계좌번호 패턴에 경계가 없어 `1955-03-21` → `1[계좌번호]` | 앞뒤 숫자·하이픈 배제 경계 추가 |
| `facts` 크기 무제한 | 요청자가 프롬프트 길이를 마음대로 늘려 비용·지연을 좌우할 수 있었다 | 16KB 상한 |
| 레이트 리밋 없음 | 모델 호출 경로가 공개 URL에 그대로 열려 있었다. 무료 한도를 태우면 **심사 기간에 데모가 죽는다** | 설명 10회/분, 판독 5회/분. IP는 남기지 않고 해시만 |
| 보안 헤더 없음 | CSP·X-Frame-Options 등 전무 | 6종 추가. `/widget` 만 `frame-ancestors 'self'` |

### 남는 한계

- **레이트 리밋은 인스턴스 메모리 기반**이다. 서버리스라 인스턴스마다 따로 센다. 폭주를 늦추는 장치지 완전한 차단이 아니다. 실서비스라면 공유 저장소가 필요하다.
- **CSP에 `unsafe-inline`이 남아 있다.** Next 하이드레이션 인라인 스크립트와 `style={{ }}` 때문이다. nonce 방식으로 없앨 수 있으나 제출 직전에 넣기엔 회귀 위험이 크다고 판단했다. XSS 싱크가 없다는 점이 근거다.
- **인증이 없다.** 로그인도 개인정보 저장도 없는 공개 계산기라 의도된 설계다. 은행 채널에 얹을 때는 그쪽 인증 뒤에 놓인다.

### 환경변수

없어도 **핵심 기능이 전부 동작한다.** 제도 판정·비용 계산·10년 시뮬레이션·퇴사 손익·
레드팀 콘솔은 LLM을 타지 않기 때문이다. 아래는 `AI 설명 받기` 와 문서 판독을 켜는 설정이다.

| 키 | 값 | 비고 |
|---|---|---|
| `AI_PROVIDER` | `gemini` | 미설정 시 `onprem` — 서버에 로컬 모델이 없어 실패한다 |
| `GEMINI_API_KEY` | 발급 키 | Google AI Studio |
| `GEMINI_MODEL` | `gemini-3.6-flash` | 생략 시 기본값 |

금융기관 내부망에 올릴 때는 `AI_PROVIDER=onprem` 과 `ONPREM_BASE_URL` 만 바꾼다.
판정과 금액은 그대로다.
