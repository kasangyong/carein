# Product Brief — 돌봄 가족 재무 내비게이터 (가칭)

작성일: 2026-09-01 · 대회: 2026 금융 AI Challenge
마감: 2026-09-07 10:00 · URL 가동 의무 09-07 11:00 ~ 09-11 23:59

## 한 문장
부모 돌봄이 시작된 자녀에게, **흩어진 제도를 조합해 향후 5~10년 재무를 계산해주고
"퇴사할까 말까" 같은 실제 결정을 근거와 함께 지원**하는 서비스.

## 왜 이 자리인가 — 인센티브의 공백

돌봄 시장의 모든 주체가 **돌봄 받는 사람**을 본다. **돌보는 사람**은 아무도 안 본다.

| 주체 | 하고 있는 것 | 돌보는 사람을 안 보는 이유 |
|---|---|---|
| KB국민은행 | KB골든라이프 요양·돌봄 (2026.8) — 기관검색·비용계산·상담 | 정보 제공에서 멈춤 |
| 신한은행 | SOL메이트 헬스케어 — 치매 시 신탁관리인 자산집행 | 대상이 시니어 **본인** |
| 하나은행 | 치매안심금융센터, 하나더넥스트 | 대상이 시니어 **본인** |
| 간병 플랫폼 (케어닥·케어네이션) | 간병인 매칭, 간병비 견적 | 간병인을 팔아야 함. "그만두지 마세요"라 할 이유 없음 |
| 보험사 | 요양시설·간병보험 | 피보험자는 부모 |
| 복지제도 | 장기요양·돌봄 급여 | 전부 **피돌봄자** 중심 설계 |

→ 돌보는 사람은 **자산이 줄어드는 고객**이라 아무의 수익원이 아니다.
   관심의 공백이 아니라 **인센티브의 공백**이고, 그래서 비어 있다.

→ 그런데 돌보는 사람은 **40~50대, 은행 핵심 고객층**이다.
   "당신들이 놓치고 있는 고객이 여기 있습니다"가 심사 메시지.

## 문제 (2026년 기준 검증 완료)

| 지표 | 값 | 출처 |
|---|---|---|
| 개인 간병인 1:1 | 하루 12~14만원 = **월 360~420만원** | 2026 |
| 전체 간병비 지출 | **12조 돌파 전망** | 2026 |
| 전형적 붕괴 | 300~400만원 필요 / 실수입 150만원 → **퇴사 → 경력단절** | — |
| 치매환자 가족 | **45.8%** 돌봄 부담 호소 | — |
| 제도 평가 | "**돌봄을 돌보는 제도는 여전히 공백 상태**" | 디멘시아뉴스 |

## 타이밍 — 제도가 지금 바뀌는 중

- **요양병원 간병비 급여화** (2026.7.28 발표): 본인부담 100% → **30%**, 월 200~267만 → 60~80만
- 2026 **하반기** 시범 200곳 → 2028년 350곳 → 2030년 500곳. 재원 6.5조
- **통합돌봄 2026.3 전국 시행**
- 노인복지 예산 27조 → **29.3조**
- 복지부 2026 업무계획 4대 과제 1순위 = **돌봄 국가책임 강화**

→ 급여화가 **극도로 선별적**(100병상↑ + 직고용 + 의료중심 200곳 + 중증도 상위 8.5만명, 요양병원만).
   요양원·재가·개인간병인은 그대로. **"내 부모가 대상인가?"가 새 난제**가 됐다.
   제도 급변기 = 정보 비대칭 최대 = 우리 자리.

## 아무도 안 해주는 계산

> 입주간병인 200만원인데 내 월급이 150만원이다. **그만두는 게 나은가?**

직관은 "그만둬라". 실제로는 경력단절 후 복귀 임금 손실, 국민연금 가입기간 손실,
퇴직금 정지, 건강보험 피부양자 전환까지 다년으로 계산해야 하고 **답이 자주 뒤집힌다.**

제도도 흩어져 있다 — 각각 요건·중복·배타 관계가 달라 조합에 따라 연간 수백만원이 갈린다.
- 가족요양비 월 240,450원 (2026)
- 가족인 요양보호사 (자격 취득 + 재가센터 근로계약)
- 가족돌봄휴직·휴가 (고용보험)
- 일상돌봄 서비스, 가족돌봄청년 지원
- 장기요양 재가급여 한도 내 조합
- 세제 공제 / 지자체 개별 제도

## 데이터 — 전부 공개 API, 개인 금융데이터 불필요

| 필요 | 확보 | 상태 |
|---|---|---|
| 복지제도 전량 (중앙부처) | 한국사회보장정보원 중앙부처복지서비스 API | 확인 (활용신청 2,194) |
| 복지제도 전량 (지자체) | 한국사회보장정보원 지자체복지서비스 API | 확인 |
| 정부 혜택 전량 | **행안부 대한민국 공공서비스(혜택) 정보 API** (JSON+XML) | 확인 |
| 장기요양기관 비용·품질 | 건보공단 장기요양기관 검색/상세조회 API + 평가결과 | 확인 |
| 등급별 급여한도·본인부담 | 건보공단 등급판정 현황 + 통계연보 | 확인 |
| 의료비·비급여 | 심평원 병원정보/의료기관상세/비급여진료비 API | 확인 |
| 부모 소득 | 국민연금 수급현황 API | 확인 |
| 자금 부족 시 | 서민금융진흥원 대출상품한눈에 API | 확인 |
| 지역 인구 | 행안부 행정동별 연령별 인구 API | 확인 |

**사용자 입력은 부모 등급·본인 소득·가족 구성 정도.** 개인 거래데이터가 필요 없어
마이데이터·오픈뱅킹 제약을 받지 않는다. 전량 실데이터.

## 원칙
1. **금액은 룰 엔진이 계산한다.** LLM은 숫자를 만들지 않는다.
2. **모든 판정에 제도 근거를 인용한다.** 근거 없으면 출력하지 않는다.
3. **결정을 대신하지 않는다.** 시나리오와 근거를 주고 선택은 사용자가 한다.
4. **개인 민감정보를 저장하지 않는다.**

## 성공 기준
- 심사위원이 URL에서 3~5분 안에 핵심 루프 재현
- 기능명세서 기재 기능 전부 실동작 (미구현 0건)
- 모든 금액에 산출 근거, 모든 제도에 출처 표시
